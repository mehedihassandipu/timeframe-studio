# Changelog

## v22
- Match **width only** or **height only** of the reference, keeping proportions (the ▾ next to MATCH SIZE).

## v21
- Gatan **DM3 / DM4** import with pixel size; stacks give one picture per frame.
- **PPTX** export: an editable PowerPoint slide.
- The grid carries its labels: Repeat copies, labels beside it and scale bars move with it; resizing scales text, scale bars and gaps (optional).
- **GAP**: type the distance between facing sides of two things; can be locked.
- Lossless **turn & flip** of pictures; free rotation of text, shapes and pictures; **groups** (⌘G).
- Colour palettes: basic, colour-blind safe, LUT colours, recent.

## v20
- LaTeX-style **formulas** in every text (`x^2`, `x_2`, `\alpha`, `$t$`), with symbol buttons, preview and help.

## v16 – v19
- Free canvas with an export frame; BrightSlide-style arranging with the reference clicked first; locks; time-series grids with titles from file names; Repeat on panels; batch export; projects that embed the original files.
